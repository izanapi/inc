# DEAD AIR — 03:17

午前3時17分、放送終了後の短波帯から「存在しない町」の声を回収する、90秒の一画面アーケードゲームです。

## 遊び方

- 画面を左右にドラッグ（または `←` `→`）して周波数を動かす
- 波形が強くなる場所に照準を合わせ続け、LOCKを満たす
- INTERFERENCEが危険になったら `PURGE`（または `SPACE`）で除去
- 連続回収でスコア倍率が上昇。赤い信号は高得点
- 90秒後に回収数・スコア・ランクを記録

マウス、タッチ、キーボード対応。効果音と短波ノイズはWeb Audio APIでリアルタイム生成するため、音声素材の読み込みはありません。

## ローカル起動

```sh
npm start
```

ブラウザで <http://localhost:8000> を開きます。

## テスト

```sh
npm test
```

GitHub Actionsがテスト後に `docs/` をGitHub Pagesへ公開します。
